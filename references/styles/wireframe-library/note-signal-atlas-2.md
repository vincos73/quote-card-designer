# Signal Atlas, prospettiva in trasformazione

Seconda composizione corrente, PNG nativo 1122 × 1402 px. Frase completa una
sola volta: «Le idee crescono quando cambiano prospettiva.»

Una mesh cambia orientamento attraversando campi chiari e scuri. Cornici,
traiettorie e allineamenti la collegano alla tipografia. Questa struttura è
un'opzione del repertorio; non è un modello fisso per ogni card Signal Atlas.

La generazione usa le stesse tre reference descritte nel prompt effettivo.
Il confronto senza reference, conservato nell'esplorazione, presentava
artefatti sulle lettere e una relazione più debole tra cornici e geometria.
Una singola coppia non isola il contributo degli input dalla variabilità
del generatore. Il profilo resta utilizzabile dalle sole istruzioni scritte.

La palette arancio è una scelta di questa prova. Testo e composizione non
certificano ripetibilità su frasi diverse.
